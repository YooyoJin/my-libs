# examples/hc32f460demo/ —— 跑板验证工程（前后台架构）

用途：真机验证各模块 + 作为新项目的起手模板。**本仓库唯一允许放 IDE 工程的地方。**

规划内容：
```
hc32f460demo/
├── demo.uvprojx        ← MDK 工程（一个工程共用所有模块）
├── main.c              ← APP 组装根：Init 全部 + while(1){ 各任务 Poll(); }
├── comm485.c/.h        ← APP 通信任务：帧业务（参数写入各模块）+ 应答
└── commdebug.c         ← 串口打印 RPM/Output 观测任务
```

前后台铁律：**中断只搬字节，主 loop 动脑子**；485 DE 脚在 TX Complete 中断里切换。

业务允许耦合（组装根是耦合合法区），但业务代码里不准出现寄存器名。

## 对拍验证流程（切换真实输出前必做）

1. 本工程与产品工程"影子运行"（只计算不输出，或输出到空闲定时器通道）
2. 串口每秒打印 GetRpm/GetOutput，与产品工程寄存器观测值对比
3. 曲线一致后切换真实 PWM 输出，跑完整自检 + 启停 50 次
